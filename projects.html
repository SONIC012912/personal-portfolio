Project 1

Breadboard and Logic Gates

More images

How the project works

The circuit is built on a breadboard. Holes in the same row are connected, so the parts can be linked, tested, and changed without soldering.

Each gate reads its inputs and gives one output. An input is either off (0) or on (1).

  • AND gate. The output is on only when every input is on. If any input is off, the output is off.
  • OR gate. The output is on when at least one input is on. The output is off only when every input is off.
  • NOT gate. There is one input. The output is the opposite: on becomes off, and off becomes on.
  • XOR gate. The output is on only when the inputs are different. If the inputs match, the output is off.

My contribution

I designed and assembled logic gate circuits using a breadboard and electronic components. I connected the required components, tested different input combinations, and observed the output of each logic gate. I also demonstrated how NOT, AND, NAND, OR, and XOR gates operate in practical circuits.

What I learned

Through this project, I gained practical experience with digital electronics and fundamental logic gates. I learned how different input combinations affect circuit outputs, how to interpret truth tables, and how to build and test basic logic circuits using a breadboard. This project also improved my circuit-building and troubleshooting skills.

How the project works

An algorithm is a list of commands. The robot carries out that list in order, and the path of those moves draws a geometric shape.

For example, a square is drawn by repeating the same two commands four times: move forward, then turn by a right angle.
