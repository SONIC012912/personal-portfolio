More images

How the project works

The circuit is built on a breadboard. Holes in the same row are connected, so the parts can be linked, tested, and changed without soldering.

Each gate reads its inputs and gives one output. An input is either off (0) or on (1).

  • AND gate. The output is on only when every input is on. If any input is off, the output is off.
  • OR gate. The output is on when at least one input is on. The output is off only when every input is off.
  • NOT gate. There is one input. The output is the opposite: on becomes off, and off becomes on.
  • XOR gate. The output is on only when the inputs are different. If the inputs match, the output is off.

My contribution

I designed and assembled logic gate circuits using a breadboard and electronic components. I connected the required components, tested different input combinations, and observed the output of each logic gate. I also demonstrated how NOT, AND, NAND, OR, and XOR gates operate in practical circuits.

What I learned

Through this project, I gained practical experience with digital electronics and fundamental logic gates. I learned how different input combinations affect circuit outputs, how to interpret truth tables, and how to build and test basic logic circuits using a breadboard. This project also improved my circuit-building and troubleshooting skills.

How the project works

An activity introduces one coding concept. Students then try that concept in an interactive task and see the result of the step they just made.

The project works by introducing participants to programming concepts and algorithms through interactive activities using Microsoft MakeCode. First, participants are introduced to the basic principles of coding and computational thinking. Then, they follow step-by-step instructions to create programs using visual coding blocks. By arranging and connecting these blocks, participants learn how algorithms work and how sequences of instructions control a program's behavior. Throughout the session, team members guide participants, explain programming concepts, and help them complete practical coding activities.

My contribution

I actively participated in organizing and delivering an Hour of AI educational event. I helped introduce participants to programming concepts and algorithms using Microsoft MakeCode. I contributed to explaining coding activities, guiding participants through practical exercises, and encouraging them to explore computational thinking. I also collaborated with my teammates throughout the preparation and teaching process.

What I learned

Through this project, I improved my understanding of algorithms, programming fundamentals, and computational thinking. I gained experience in using Microsoft MakeCode as an educational tool and learned how to explain technical concepts in a simple and engaging way. The project also strengthened my teamwork, communication, problem-solving, and presentation skills.

How the project works

An algorithm is a list of commands. The robot carries out that list in order, and the path of those moves draws a geometric shape. For example, a square is drawn by repeating the same two commands four times: move forward, then turn by a right angle.

For example, a square is drawn by repeating the same two commands four times: move forward, then turn by a right angle.

The robot operates using programmed algorithms that control its movement along a predefined line. The LEGO Mindstorms EV3 programmable brick processes instructions and controls the motors to guide the robot along the path. Sensors, including the Gyro Sensor, help monitor the robot's movement and detect rotation angles for more accurate navigation. By executing a sequence of programmed instructions, the robot can follow different paths autonomously without manual control.

My contribution

I contributed to programming and developing the line-following robot using LEGO Mindstorms EV3. I worked with robotics algorithms and motor control to determine how the robot should move along predefined paths. I also participated in testing the robot, observing its movements, identifying errors, and improving the program to achieve smoother and more accurate performance.

What I learned

Through this project, I gained practical experience in robotics, algorithm development, and autonomous systems. I learned how to control motors, work with sensors, and translate programming instructions into physical movements. I also improved my problem-solving, debugging, teamwork, and logical thinking skills. Most importantly, I understood how software and hardware work together to create an autonomous robot.
